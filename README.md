# East-africa-digital-adoption
A comparative data analysis of internet and mobile adoption in Kenya, Uganda, Tanzania, Rwanda and Ethiopia from 2000 to 2024
  #Key findings
- Kenya had the highest internet use in 2024 at 35.0%, up from 7.2% in 2010.
- Tanzania had the biggest internet gain since 2010 (+28.3 points), just ahead of Kenya (+27.8).
- Uganda's internet use barely changed (+4.7 points), and its data drops in 2020, so treat it with caution.
- Mobile subscriptions are far higher than internet use. Kenya has 126 per 100 people but only 35% online.
